# 🎨 NAI 生图插件 (`astrbot_plugin_nai_image` v2.2.0)

基于 **NovelAI Diffusion V4.5 / V5** 的 AstrBot 绘图插件。内置 **19,663 条实测 Tag 法典词库**，支持**多槽位（名称 + 模型 + 画师串）预设管理**、**V4.5 / V5 模型级 Tag 物理隔离**、**原生多角色块 (`characterPrompts`) 防串色架构**以及独立 Web 调试面板。

---

## ✨ 核心特性

### 1. 🗂️ 三合一预设槽位系统（前后端独立）
- **自定义名称 + 绑定模型 + 专属画师串**：支持自由新建、修改、删除多个预设槽位，每个槽位直接绑定对应的生图模型（如 `nai-diffusion-4-5-full` 或 `nai-diffusion-5-full`）与专属画师串。
- **Web 测试槽位与后端正式槽位物理分离**：
  - **Web 测试面板**：切换槽位、微调参数点击测试生图，仅在面板内生效，**绝不覆盖**后端正式聊天配置。
  - **后端插件设置**：在插件「配置」弹窗中提供独立的 **「后端正式生图启用槽位」** 下拉框（自动同步面板中新建/修改的所有槽位），平时 Bot 聊天与 AI 工具生图固定使用后端所选槽位。

### 2. 📖 内置 1.96 万条实测法典词库 & 模型级硬隔离
- **开箱即用**：插件内置压缩词库 `data/grimoire.db.gz`（首次运行自动解压），共收录 **19,663 条** 经过实测的 Tag 组合：
  - **NAI V4.5 专卷（18,505 条）**：含 N4.5 常规卷（5,893 条）、色色卷一~卷四（12,057 条）及穿搭专卷（555 条）。
  - **NAI V5 专卷（1,158 条）**：含 N5 常规卷（238 条）、N5 色色上/下卷（920 条）。
- **V4.5 / V5 严格防串 Tag**：
  - 无论是在 Web 面板切换模型、AI 调用 `NAI_Search_Grimoire` 检索法典、展开提示词中的 `【法典:词条名】` 宏，还是自然语言转译匹配参考词条，底层均**强制锁定当前生效模型的专属词库**，彻底杜绝使用 4.5 模型时误塞入 5 的 Tag。

### 3. 👥 NovelAI V4.5 / V5 原生多角色块架构 (`characterPrompts`)
- AI 自主生图工具 `NAI_Generate_Image` 采用原生分块架构：
  - `prompt`（全局主块 `base_caption`）：仅填人数、环境背景、光影氛围与镜头视角（底层自动前置当前槽位的自定义画师串）。
  - `char1_prompt`（角色块 1）：主角色外貌、穿搭、动作与神态（底层自动前置后台配置的 `character_preset` 角色固定外貌底模并自动去重）。
  - `char2_prompt`（角色块 2，可选）：双人互动时的第二角色特征与互动动作（如 `source#hug` / `target#hug`），与角色块 1 物理隔离，彻底解决双人串色问题。
- **自适应衣柜联动**：若检测到安装了 `astrbot_plugin_daily_outfit` 衣柜插件，自动激活实时穿搭挂载；若未安装，则完全隐藏衣柜相关参数与界面，作为纯粹的通用生图插件独立运行。

### 4. 🔌 官方原生接口 & OpenAI 兼容接口双协议自适应
- 在 `openai_api_base_url` 中填入地址即可自动识别：
  - **NovelAI 官方原生协议**（如 `https://image.novelai.net/ai/generate-image` 或以 `/ai/generate-image` 结尾的官方原生反代）：自动发送 V4.5 原生参数并自动解包返回的 ZIP / PNG 字节流。
  - **OpenAI 兼容图像协议**（如 `/v1/images/generations`、`/v1/images/edits` 中转站）：自动解析 `b64_json` 或下载图片 URL，并透传高级参数（Vibe 参考、Director 精准参考、img2img、多角色坐标）。

## 🛠️ 聊天指令一览

| 指令 | 说明与示例 |
| :--- | :--- |
| `/image <提示词> [--参数=值]` | 手动指令生图，支持单次参数覆盖：<br>`/image 1girl, solo, smile --size=832x1216 --steps=28 --scale=6`<br>支持多角色坐标：`--char="1girl, smile|0.4|0.5" --char="1boy|0.6|0.5"` |
| `/法典 <关键词>` | 检索当前模型版本下的内置法典词条（别名：`/grimoire`、`/查法典`）<br>亦可在提示词中直接写 `【法典:词条名】` 自动展开 |
| `/nai_interrogate` | 回复一张图片或附带图片发送（别名：`/反推`、`/nai反推`），反推 Danbooru / NAI 英文标签 |
| `/usage [天数\|today\|all]` | 查看按日期聚合的生图次数与估算点数统计（别名：`/用量`、`/统计`） |
| `/imgstatus` | 查看当前生图接口配置、模型与会话连接状态 |

---

## 🤖 AI 工具 (LLM Tools)

1. **`NAI_Generate_Image`**：供大模型在对话中自主调用生成图片（支持 `prompt`、`char1_prompt`、`char2_prompt`、`style`、`size_cn`）。
2. **`NAI_Search_Grimoire`**：供大模型在绘制特定画风、服饰或复杂互动姿势前检索当前模型专属的实测 Tag 组合。

---

## ⚙️ 快速配置指南

1. 安装插件后，打开 AstrBot 后台 -> **插件** -> 找到 **「NAI生图插件」**：
   - 点击 **「配置」**：填入 `openai_api_base_url`（生图接口地址）与 `openai_api_key`（密钥），按需填写 `character_preset`（角色固定外貌底模，留空则不附加）。
   - 点击 **「测试面板 (test-panel)」**：可新建/编辑多个「名称 + 模型 + 画师串」槽位，点击「💾 保存槽位列表」即可同步至后端配置下拉框中供正式选用。
